# Data Science & Generative AI

### Warwick Business School | University of Warwick

## About This Repository

This repository contains my coursework and practical assignments for the Data Science & Generative AI module at Warwick Business School.

The work focuses on developing practical programming and analytical skills, with an emphasis on using Python to organise, manipulate and interpret data. As the module progresses, I will document my work across data preparation, feature engineering and generative AI, alongside the methods and concepts explored in each assignment.

The repository also serves as a record of my technical development throughout the module.

## Coursework

### Assignment 1 — Data and Feature Engineering

This assignment introduces data manipulation using Pandas and NumPy, focusing on how different Python data structures can be converted into formats suitable for analysis.

Key areas explored include:

- Creating and manipulating Pandas DataFrames
- Working with dictionaries, lists and structured datasets
- Using NumPy for numerical data generation
- Identifying missing values and understanding their implications for data quality
- Considering how data preparation influences subsequent analysis

## Assignment 2 — Data Transformations and Exploratory Data Analysis (EDA)

This assignment covers data cleaning, transformations, handling missing values, currency conversions, grouping operations, and performing Exploratory Data Analysis (EDA) with visualizations using Seaborn and Matplotlib.

Key areas explored include:
* Concatenating DataFrames across multiple sheets and files
* Identifying and handling missing values (NaNs) and duplicates
* Currency conversion and data-type/date-time transformations
* Data aggregation using groupby() with means and medians
* Visualising data distributions and correlations using bar charts, scatter plots, histograms, and pairplots

**[View Assignment 2 Notebook](Assignment_2/)**

Assignment 3 — Machine Learning Models: Classification and Regression
This assignment covers supervised machine learning techniques, exploring the transition from traditional statistical modeling to predictive machine learning through decision trees, logistic regression, and regularized linear regression.
Key areas explored include:
- Implementing and tuning Decision Tree classifiers using `RandomizedSearchCV`
- Optimizing classification models for macro-recall to minimize false negatives in medical datasets
- Comparing traditional Ordinary Least Squares (OLS) statistical modeling with machine learning workflows
- Applying $L1$ regularization (Lasso) to manage feature selection, coefficient shrinkage, and model complexity
- Evaluating model performance using stratified train-test splits, confusion matrices, and $R^2$ metrics
