## About This Repository

This repository contains my coursework and practical assignments for the Data Science & Generative AI module at Warwick Business School.

The work focuses on developing practical programming and analytical skills, with an emphasis on using Python to organise, manipulate and interpret data. As the module progresses, I will document my work across data preparation, feature engineering and generative AI, alongside the methods and concepts explored in each assignment.

The repository also serves as a record of my technical development throughout the module.

## Coursework

### Assignment 1 — Data and Feature Engineering

This assignment introduces data manipulation using Pandas and NumPy, focusing on how different Python data structures can be converted into formats suitable for analysis.

Key areas explored include:

- Creating and manipulating Pandas DataFrames
- Working with dictionaries, lists and structured datasets
- Using NumPy for numerical data generation
- Identifying missing values and understanding their implications for data quality
- Considering how data preparation influences subsequent analysis
